# Yomu 1.0.0-alpha25

## Voices

- Fish Audio is a full online provider alongside Azure Speech and ElevenLabs. It can be
  the primary provider, it takes part in the playback and MP3 export fallback chains, and
  its licensed voice catalog loads from Settings. It uses Fish Audio's free S2.1 Pro
  model, so no paid plan is required.
- Every voice can be starred, including the offline Kokoro voices. Starred voices collect
  in one section that can preview and select them. Starring is scoped per provider, so the
  same voice id from two providers never collapses into one entry.
- Voice previews are cached on disk by provider and voice id. Previewing a voice again
  costs no provider call, no network time, and no provider quota. Samples are written
  atomically so an interrupted download is never replayed, and the cache is bounded and
  pruned by last use. Changing a provider key discards that provider's samples.
- Provider failures are now reported with their reason instead of being swallowed. An
  Azure or ElevenLabs outage says why, rather than silently falling back to the offline
  voice.
- The private website access key can be copied to the clipboard or shown again in
  Settings, so a browser or the extension can be paired without digging through the
  server host.

## Web reading view

- The reading view has an Actions menu with the same operations as the library list:
  mark read or unread, add to or remove from Up next, move within Up next, archive or
  restore, rename, add to or remove from a playlist, and delete.
- The end of an article offers archiving or deleting it directly. Archive keeps the
  article in the library, out of To read; delete removes it and its reading history.
- The library and the reader share one definition of each action, so they cannot drift
  apart.

## Library and inbox

- Newsletter inbox with email previews, automatic playlist routing, and routing rules.
  Newsletter paragraphs are preserved rather than flattened.
- Inbox multi-select with atomic bulk playlist assignment, long-press selection, and a
  pinned assignment toolbar. New phone playlists are offered when assigning.
- Long-press selects articles in the main library, and Up next is available from the
  article overflow menu.
- Search and labelled filter sheet in the mobile library, with larger selection touch
  targets.
- Failed imports can be removed recoverably, and a floating source review shows why an
  import failed.
- Duplicate article saves are recognised across tracked URL variants.
- Inbox and History navigation positions swapped.

## Appearance and site

- Settings text contrast is consistent across light and dark themes and custom accent
  colours, and the dark screen text contrast regression is fixed.
- Settings back navigation and light toolbar contrast are fixed, and disclosure headers
  use rounded rectangles.
- The branded landing page and help pages are published, with a distinct dark variant
  under the Atomic 22 Industries publisher identity.

## Install

Download the matching debug APK attached to this GitHub release. Installing this build is
an in-place update over the previously installed alpha and should preserve the app's
local data, including saved provider keys and starred voices.
