# Yomu 1.0.0-alpha14

## Fixes

- Fixed Play now's foreground-service startup timeout. The visible app starts the playback service without requesting foreground mode prematurely; Media3 promotes it when audio playback begins, after article loading and speech synthesis.

## Validation

- `:app:testDebugUnitTest` passed.
- `:app:assembleDebug` passed.
- `:app:assembleDebugAndroidTest` passed, including compilation/package of the instrumentation APK.
- The fix has not been installed on the Galaxy yet, so device-level playback validation remains pending.

## Install

Download the matching debug APK attached to this GitHub release. Installing this build is an in-place update and should preserve the app's local data.
